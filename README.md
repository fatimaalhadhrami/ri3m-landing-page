# RI3M — Streetwear Coming Soon Landing Page

A modern coming-soon landing page concept designed for a fictional streetwear and athletic-wear brand.

## Overview

RI3M is a responsive landing page created to practice and demonstrate front-end web development and UI design skills.

The page focuses on a bold, minimal streetwear aesthetic using strong typography, generous spacing, product photography, and a red, black, and off-white color palette.

## Features

* Responsive design for desktop, tablet, and mobile
* Coming-soon hero section
* Live countdown timer
* New Drops product section
* Email notification form
* About section
* Social media links
* Hover interactions
* Mobile-responsive layout

## Technologies

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## Design

The visual direction was inspired by modern streetwear and athletic fashion websites.

### Color Palette

* Off-white: `#F5F4F0`
* Red: `#8D1818`
* Black: `#111111`

## Project Purpose

This is a personal portfolio project created to demonstrate front-end development, responsive design, and UI implementation skills.

It is not a commissioned client project.
